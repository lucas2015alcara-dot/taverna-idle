# Taverna Idle (nome provisório)

Idle RPG mobile de coleção de heróis em fantasia medieval: você herda uma taverna na fronteira do reino e contrata heróis para enfrentar monstros que saem de uma fenda no céu.

- Status: pré-produção
- Plataforma: Android (Google Play), feito em HTML5/JavaScript
